# Իմ մասին

![](../images/avatar-photo.jpg)

Ողջու՜յն, ես Պապյան Արենն եմ։ Սովորում եմ Դիլիջանի Կենտրոնական դպրոցում 2016 թվականից ի վեր։ 16 տարեկանում դարձա Fab Academy-ի աշակերտ։ Այժմ փորձելու եմ իրականացնել իմ երազանքները։
Հետաքրքրված եմ քիմիայով, ֆիզիկայով, ծրագրավորմամբ և ինժեներիայով։

Այցելի՛ր իմ էջը, ավելի մանրամասն իմ աշխատանքների մասին իմանալու համար։

## Կենսագրություն

Ծնվել եմ Հայաստանի փոքրիկ ու գեղեցիկ քաղաքում՝ Դիլիջանում։
